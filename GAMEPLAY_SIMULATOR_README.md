# DATA TYCOON — Gameplay Capture Simulator

`gameplay-simulator.html` oyundan bağımsız, video kaydı için hazırlanmış otomatik gameplay simülasyonudur.

## Kayıt
1. `gameplay-simulator.html` dosyasını Chrome/Edge'de açın.
2. Tarayıcıyı tam ekran yapın (F11).
3. Windows Game Bar ile kaydı başlatın: `Win + Alt + R`.
4. Sayfayı yenileyin veya sağ alttaki `↻` düğmesine basın.
5. Yaklaşık 60 saniye boyunca simülasyon otomatik oynar.
6. `Win + Alt + R` ile kaydı durdurun.

Simülasyon gerçek kariyer save'ine erişmez ve değiştirmez.
